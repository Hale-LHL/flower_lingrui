## II-初识卷积神经网络
### 一. 一张 RGB 三通道彩色图片是如何被处理成可用于训练的数据？张量又是什么？
1.  RGB 三通道彩色图片首先被转化成张量（此时已经算得上是可用于训练的数据了），然后拆分成R、G、B三张矩阵图（三维变二维），接着再用卷积核进行卷积运算，进一步提取特征，转化成为更方便进行训练的数据。
2. 张量是三维的一种数据形式（从0维到2维都有特殊的名称，依次是数，向量，矩阵，张量），张量是一种方便计算机计算的一种数据，特别是能够让计算机进行并行运算和利用显卡计算。一张彩图的数据可以形成三维张量（也叫三阶张量）（高，宽，色彩），再拓展，可以用四阶张量表示一个包含多张图片的数据集（编号，高，宽，色彩）

> 三阶张量如下图：
![张量.jpg · 49](https://img.cdn1.vip/i/6ac5d12fd3e9a_1791349039.webp)
### 二. 一个卷积神经网络分为哪几层？
- 卷积神经网络是一个训练模型的范式（卷积神经网络应该还算不上一个模型，因为其并没有确定使用的参数）。卷积神经网络常有这些层：输入层、卷积层、激活层、池化层、全连接层、输出层，以上为层的种类，具体的层数以具体的训练效果做参考。
>激活层是否单独存在在不同文章中说法不同，也有的文章认为激活函数是附着于卷积层的工具，不单独分层

>卷积层、激活层、池化层常组成为一个整体多层叠加，也就是（卷积层+激活层+池化层）*n，当然也有的时候不加池化层，输出层也常常不加激活层。
### 三.什么是卷积，数学严格意义上的卷积和神经网络中的卷积操作有区别吗？卷积核、步长是什么？
1. 卷积是一种数学运算，通过将两个函数翻转、平移并叠加乘积，生成一个新的函数，用于描述系统对输入的累积响应。
2. 有区别：最明显的是，神经网络里的卷积是没有经过翻转这一步的，是通过学习得到卷积核之后，直接惊醒平移并叠加乘积；其次神经网络里的卷积的两个函数是小范围的二阶张量。
3. 卷积核：是对图片张量进行特征提取的过滤器，也是一张小的、可学习的权重表，直接执行逐元素的乘法和加法，卷积核的不同会引起不同的后果，比如边缘淡化，锐化，突出某一特征等。（卷积核一般由训练获得，**靠反向传播 + 优化器训出来的**）
4. 步长：指卷积核一次平移的像素点数，一般会影响训练的精度和计算量。
### 四.池化有哪些类型，其作用分别有什么？感受野是什么？
1. 池化的类型及具体作用
- 最大池化：取每个池化窗口的最大值，能提高模型鲁棒性，突出了显著特征
- 平均池化：取每个池化窗口的平均值，能把随机噪声被平均掉，数据更稳
- 重叠池化：相邻池化窗口有重叠部分，提高精度防止造成边缘附近数据相关性的遗漏，还可减弱过拟合（因为增强了一些些鲁棒性，不是因为增加了数据）
- 空间金字塔池化：池化窗口分别取1*1，2*2，3*3……,每个窗口取最大值；避免了为适应全连接层而对图像进行裁剪/伸缩造成的误差。
- 随机池化：根据池化窗口内元素的值按随机选择，增强模型泛化能力，减少过拟合
- 混合池化：结合最大池化和平均池化的优点，同时提取最大值和平均值，提取更丰富的特征信息 
- 全局池化：把高宽压到1，顶替全连接层、把参数量砍掉几个数量级，防止过拟合
2. 池化的共同作用：    
降维，减小计算；增加鲁棒性（降低对部分噪音，大小变换，平移的敏感程度，因为无论有没有噪音，池化会让他们变得类似）；以防过拟合（减少参数量）
3. 感受野：每一层输出的特征图上某个像素点所对应的原始图像上的区域大小，第一层的输出特征图一个像素点对应的原始图像区域等于卷积核的大小，而其他卷积层输出特征图一个像素点对应的原始图像区域与之前所有层的卷积核大小和步长有关。简单来说，**感受野**就是之后的像素点包含或者简化的原始图像的面积。卷积+池化的组合能较快速的增大感受野。**
- 理论感受野：通过卷积核大小，步长，层数计算的感受野大小。公式如下：
![理论感受野.png · 80](https://img.cdn1.vip/i/6ac5d12eda637_1791349038.webp)
- 有效感受野：随着网络的加深，感受野外部的信息会丢失，且会有空隙，会不对称（这是因为权重随机初始化），可以通过将一个特征像素点反向传播看真正有贡献的原始图像有多大来看出有效感受野的大小。未训练的有效感受野成高斯分布，带有空隙。
### 四.激活层在此的作用？最后卷积神经网络会输出什么？
![卷积神经网络 .png · 512](https://img.cdn1.vip/i/6ac5d12f4d3f1_1791349039.webp)
1. 卷积操作是由输入矩阵与卷积核矩阵进行计算，本质上是WX+B（W,X,B为矩阵），如果不加激活层，多次卷积可以等效为一次，做的是无用功。激活层可以对卷积层的输出层进行非线性的映射，让输出的特征图具有非线性，增加模型复杂度，提高模型的性能。
2. 最后卷积神经网络会输出分数（有正有负，且和不一定为0），可通过softmax转为概率，利于分类。（分数有正有负也是不能用输出层不能用relu的原因之一）

1. 数据集中存在异常或者损坏的图片无法打开（图片默认格式为jpg）：

通过两次识别判断是否出错，如果出错，将异常的图片移动到特定文件夹，并且在.txt文件中记录异常图片的来源
```commandline
# preproccess.py============================ 坏图检测 ============================
def handle_bad_img(logs_dir=LOGS_DIR, bad_img=BAD_IMG, train_dir=TRAIN_DIR, test_dir=TEST_DIR):
    os.makedirs(logs_dir, exist_ok=True)
    bad_img = open(bad_img, 'w', encoding='utf-8')
    # 'w' 为每次清空重写，'a' 为追加记录；open() 的返回值必须用一个对象接住
    # encoding='utf-8'：写中文用哪套编码，读的时候也得用同一套，否则 Windows 用默认的 GBK 会乱码
    all_img_sort_dir = [test_dir, train_dir]
    bad = []
    bad_img.write('以下为坏图：\n')
    for img_sort_dir in all_img_sort_dir:
        for img_sort in os.listdir(img_sort_dir):  # listdir 不接受列表
            img_sort_path = os.path.join(img_sort_dir, img_sort)
            if not os.path.isdir(img_sort_path):  # 不是文件夹就跳过
                continue
            for img in os.listdir(img_sort_path):  # 还要再进一层类别（sort）文件夹
                img_path = os.path.join(img_sort_path, img)  # listdir 只返回文件名，必须拼回完整路径
                try:
                    img = Image.open(img_path)
                    img.verify()  # 只读文件头，快，但抓不全所有坏图
                    img = Image.open(img_path)
                    img.load()  # 真正解码像素，能抓出 verify 漏掉的坏图
                    result = True
                except Exception:
                    result = False
                if not result:  # not result ,即 result 为 False 时进行
                    bad.append(img_path)
                    bad_img.write(img_path + '\n')
    bad_img.close()
    if bad != []:
        broken_dir = os.path.join(logs_dir, "broken")
        os.makedirs(broken_dir, exist_ok=True)
        for p in bad:
            # os.path.dirname() 往左砍掉最后一段，返回剩下的
            # os.path.basename() 往右取最后一段
            name = os.path.basename(os.path.dirname(os.path.dirname(p))) + "_" + os.path.basename(os.path.dirname(p)) + "_" + os.path.basename(p)
            dst = os.path.join(broken_dir, name)
            if not os.path.exists(dst):  # 目标位置没有同名文件才移动
                shutil.move(p, dst)  # 剪切，不删除，随时可还原
    return bad
```

```commandline
    n = len(dataset)
    n_val = int(round(n * val_size))  # random_split 的长度必须是整数
    n_train = n - n_val  # 用减法保证 n_train + n_val == n，不会漏样本

    return train, val
```

### 一. 概念问题
1. 什么是超参数？如何设定？
![超参数 .png · 198](https://img.cdn1.vip/i/6ac5d12ddeb0a_1791349037.webp)
超参数是训练前由人来手动决定的参数（还包括了优化器的选择，也算是超参数），用于其他参数的学习，但超参数本身不随学习训练变化。
超参数的设定有两种方法：
- 其一：按照经验去试，就像用了adam后设置lr大多在0.001附近，可以通过多次训练，根据验证集的表现进行调整。
- 其二：通过算法进行选择，如：网格搜索(Grid Search)，随机搜索(Randomized Search)，贝叶斯优化(Bayesian Optimization)，Hyperband等等（各个方法暂时没有详细了解）
2. 什么是优化器，有哪些类型？    

优化器是对参数修正的方法进行优化，通过加入惯性或是自适应学习率等，让模型找到最佳参数组的效率变高，防止掉进局部最小值

| 优化器 | 核心机制                                           | 
|---|----------------------------------------------------|
| SGD | 纯靠梯度修正参数                                   | 
| SGD+Momentum | 有惯性，冲过浅谷                                   | 
| AdaGrad | 累加平方梯度，学习率逐维衰减                       | 
| RMSProp | 减弱梯度大小带来的影响                             | 
| Adam | 动量 + RMSProp，最常用                             | 
| AdamW | Adam + 解耦权重衰减（要用L2正则时，AdamW比Adam好） | 


3. DataLoader 与 DataSet是什么及其使用？（可调库）

- dataset是管理两件事——数据从哪里拿，数据拿哪一个。如果不用dataset计算机根本不知道数据从哪里拿，也不知道怎么拿。dataset想实现的是什么数据都能被用，只要他能被读取出长度__len__，有一一编号__getitem__。
- dataloader是管理把数据给模型进行训练前的数据处理，他会把数据切成一块一块的，也可以将其中的数据打乱，以便于模型的学习。
- 值得注意的是dataloader的建立，必须要数据经过了dataset
- dataset的使用，有时直接调库，有时要自定义（自定义数据或csv数据等）;dataloader始终调库

### 二.网络设计
```
class Mymodel(nn.Module):
    def __init__(self,n_classes):
        super(Mymodel, self).__init__()#继承nn.Module必写
        self.conv1 = nn.Conv2d(3, 96, kernel_size=11, stride=4)
        self.conv2 = nn.Conv2d(96, 256, kernel_size=5, padding=2)#kernel_size=5, padding=2让特征图大小不变
        self.conv3 = nn.Conv2d(256, 384, kernel_size=3, padding=1)#kernel_size=3, padding=1让特征图大小不变
        self.conv4 = nn.Conv2d(384, 384, kernel_size=3, padding=1)
        self.conv5 = nn.Conv2d(384, 256, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(kernel_size=3, stride=2)#下一层 = （上一层+1）/2
        self.fc6 = nn.Linear(256 * 6 * 6, 4096)
        self.fc7 = nn.Linear(4096, 4096)#Dense = 全连接层
        self.fc8 = nn.Linear(4096, n_classes)#只有5种花，所以不用图中的18
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(0.5)
        self.flatten = nn.Flatten()

    def forward(self, x):
        x = self.pool(self.relu(self.conv1(x)))
        x = self.pool(self.relu(self.conv2(x)))
        x = self.relu(self.conv3(x))
        x = self.relu(self.conv4(x))
        x = self.pool(self.relu(self.conv5(x)))
        x = self.flatten(x)#压成一维进全连接层
        x = self.dropout(self.relu(self.fc6(x)))
        x = self.dropout(self.relu(self.fc7(x)))
        x = self.fc8(x)#只有这个不加激活函数，不然会失去表达负数分的能力
        return x
```
